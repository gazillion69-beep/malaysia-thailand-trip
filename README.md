# Malaysia + Thailand Trip 2026

A mobile-friendly GitHub Pages itinerary for a 2-adult trip:

**Hyderabad → Kuala Lumpur → Phuket → Bangkok → Hyderabad**  
**Sep 22 – Oct 2, 2026**

## Privacy
This public site intentionally omits airline booking references, PNRs and other sensitive reservation identifiers.

## Publish with GitHub Pages
After uploading these files to the repository:

1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select the default branch (usually `main`)
4. Select **/(root)**
5. Save

The site entry point is `index.html`.
